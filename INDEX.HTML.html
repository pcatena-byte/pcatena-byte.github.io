🔍 Inspección del Componente

Header / Navbar

Encabezado principal con el logotipo, menú de navegación básico y botón de llamada a la acción.

Elementos Clave:
  • Logo corporativo (izquierda)
  • Menú de enlaces rápidos
  • Botón CTA (ej. Registrarse / Login)
Comportamiento Móvil:

En pantallas pequeñas, el menú de navegación se oculta dentro de un menú hamburguesa (🍔).
